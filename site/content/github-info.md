## Recent updates (August 2026)

- **Copilot cloud agent now works in Microsoft Teams.** Mention `@GitHub` in a Teams channel, thread, or DM to start a Copilot cloud agent session that the whole conversation can watch and steer together — handy for turning meeting action items into in-progress work. (Source: GitHub Changelog)
- **The GitHub Copilot experience in Slack is in public preview.** The Slack integration now brings Copilot CLI and Copilot app agentic capabilities directly into Slack conversations, so teams can go from discussion to shipped work without switching tools. (Source: GitHub Changelog)
- **Agent Plugins 1.0 is now an open standard.** Published with AWS, Anysphere, Microsoft, OpenAI, Vercel, and Google, it lets you build a plugin once (skill + MCP server bundle) and use it across VS Code, Copilot CLI, and the Copilot app instead of duplicating it per client. (Source: GitHub Changelog)
- **Copilot code review effort levels are generally available.** Choose lighter or deeper review scrutiny per pull request — quick checks for docs and small fixes, deeper analysis for complex or security-sensitive changes. (Source: GitHub Changelog)
- **Branch protection rules can now auto-migrate to repository rulesets.** A new one-click conversion in repository settings moves existing branch protection policies to GitHub's more flexible ruleset framework without manual recreation. (Source: GitHub Changelog)
- **Smaller issue and project UX improvements shipped together**, including reaction avatars on issues, adjustable Issues Dashboard density, hiding closed sub-issues, and pinning saved views to the repository sidebar. (Source: GitHub Changelog)
