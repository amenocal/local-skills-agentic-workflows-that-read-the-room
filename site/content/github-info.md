## Recent GitHub updates (September 2026)

- **Copilot code review gets smarter.** New auto-resolution and analysis updates help Copilot code review automatically clear stale comments and surface deeper findings. (Source: GitHub Changelog, Sep 11)
- **Configure cost vs. quality for Copilot's auto model selection.** Admins can now tune whether Copilot favors cheaper or higher-quality models when it picks one automatically. (Source: GitHub Changelog, Sep 14)
- **Copilot suggests custom properties definitions.** Copilot can now propose repository custom property definitions for you, cutting down manual setup. (Source: GitHub Changelog, Sep 15)
- **VS Code agent usage now shows in Copilot usage metrics.** Teams can track agent activity from VS Code alongside other Copilot usage data. (Source: GitHub Changelog, Sep 11)
- **SHA-1 over HTTPS is being retired on GitHub.com.** If you rely on SHA-1 for Git operations over HTTPS, plan to migrate before the sunset date. (Source: GitHub Changelog, Sep 15)
- **"Copilot app for Beginners" video series continues.** New installments cover running multiple agents at once and automating Dependabot pull request triage — good practical watch for developers ramping up on Copilot. (Source: GitHub Blog)
- **Decoding the new AI lingo.** A plain-language explainer of terms like loops, harnesses, squads, and hill climbing that show up in agentic AI coverage. (Source: GitHub Blog)
