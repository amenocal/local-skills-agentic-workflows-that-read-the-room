## Latest updates (September 2026)

- **Copilot code review can now approve pull requests** — Copilot's review comment now includes an approval assessment telling you whether it thinks a PR is ready to approve, and admins can let Copilot actually approve. Off by default; public preview for Pro, Pro+, Max, Business, and Enterprise plans. *(GitHub Changelog)*
- **Content exclusions now enforced in the Copilot app and CLI** — Copilot skips excluded files as context in these surfaces too, helping keep sensitive code out of agentic workflows. Available for Copilot Business and Enterprise. *(GitHub Changelog)*
- **GitHub CLI adds media support** — `gh` can now attach images and other media to issues, pull requests, and comments; generally available to everyone. Update your CLI to get it. *(GitHub Changelog)*
- **Better label management is generally available** — Issue labeling gets smarter suggestions based on repo usage plus a "Recent labels" list based on your own history, making it faster to tag issues in repos with long label lists. *(GitHub Changelog)*
- **Claude Fable 5.1 in GitHub Copilot** — Anthropic's newest Mythos-class model is now available for Copilot, tuned for long-running, autonomous coding tasks like deep codebase research and complex agentic workflows. *(GitHub Changelog)*
- **Turn one giant AI-generated PR into a reviewable stack** — A practical walkthrough on breaking a huge AI-authored pull request into smaller, reviewable stacked PRs so human reviewers can actually keep up. *(GitHub Blog, Engineering)*
- **Decoding the new AI lingo** — A plain-language glossary for terms developers are hearing more often around agentic coding: loops, harnesses, squads, and hill climbing. Useful primer if Copilot's agent terminology feels unfamiliar. *(GitHub Blog)*
