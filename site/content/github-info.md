- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent updates

- **Copilot code review can now approve pull requests** — Copilot's automated review can mark a PR as approved when the change looks good, speeding up low-risk merges. (Source: GitHub Changelog)
- **Claude Fable 5.1 and GPT-6 "Astra" now generally available in GitHub Copilot** — two new model options join the Copilot model picker for chat and coding tasks; Gemini 3 8 Flash also rolled out the same week. (Source: GitHub Changelog)
- **GitHub CLI adds media support in issues, PRs, and comments** — you can now attach images/videos to issues, pull requests, and comments directly from `gh`. (Source: GitHub Changelog)
- **Enterprise live migrations from GHES to GHE.com are generally available** — enterprises can move from GitHub Enterprise Server to GitHub Enterprise Cloud with minimal downtime. (Source: GitHub Changelog)
- **New API endpoint for privacy-safe star history data** — a public API now exposes repository star trends without exposing individual user identities. (Source: GitHub Changelog)
- **CodeQL 2.26.4 improves GitHub Actions security detections** — the latest CodeQL release strengthens scanning for risky patterns in Actions workflows. (Source: GitHub Changelog)
- **How AI code generation works** — a plain-language explainer on what happens under the hood when Copilot generates code, useful for developers new to AI pair programming. (Source: GitHub Blog)
- **A guide to slash commands in the GitHub Copilot app** — practical walkthrough of using slash commands to speed up common Copilot tasks. (Source: GitHub Blog)
- **How we took malware advisories beyond npm** — GitHub's security team expanded malware advisory coverage to more package ecosystems, helping developers catch compromised dependencies earlier. (Source: GitHub Blog)
