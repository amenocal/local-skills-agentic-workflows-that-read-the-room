- **Block pull requests with exposed secrets from merging** — Repos can now stop a PR from merging if secret scanning finds an exposed credential, closing a common leak path. ([GitHub Changelog](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging))
- **Refreshed repository pull requests page (public preview)** — A redesigned PR list makes it easier to scan status, reviewers, and checks at a glance. ([GitHub Changelog](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview))
- **GitHub Copilot app for Beginners: diff, terminal, and browser** — A beginner-friendly walkthrough of reviewing diffs, running terminal commands, and browsing docs from inside the Copilot app. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/))
- **GitHub Copilot app for Beginners: run several agents at once** — Shows how to kick off multiple Copilot coding agents in parallel and track their progress. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/))
- **Decoding the new AI lingo** — A plain-language glossary for terms like loops, harnesses, squads, and hill climbing that keep showing up in AI coding discussions. ([GitHub Blog](https://github.blog/ai-and-ml/decoding-the-new-ai-lingo-loops-harnesses-squads-hill-climbing-oh-my/))
- **New models available in Copilot** — GPT-6 Astra and Gemini 3.8 Flash both reached general availability in GitHub Copilot, giving developers more model choice. ([GitHub Changelog](https://github.blog/changelog/2026-09-04-gpt-6-astra-is-generally-available-in-github-copilot), [GitHub Changelog](https://github.blog/changelog/2026-09-03-gemini-3-8-flash-is-now-available-in-github-copilot))
