- GitHub collaboration basics: repositories, branches, pull requests, and merges.

## Recent updates

- **Migrating the GitHub Copilot runtime to Rust, using Copilot** — GitHub used Copilot itself to help port its 800,000-line Copilot agent runtime from TypeScript/Node.js to Rust, a rewrite that agentic tooling made newly affordable. ([GitHub Blog](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/))
- **GitHub Copilot app for Beginners: Using the diff, terminal, and browser** — A walkthrough of reviewing agent-generated code without tab-hopping: view diffs, run terminal commands, and preview web apps side by side in the Copilot app. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/))
- **Workflow execution protections in GitHub Actions are now generally available** — Define an allowlist to control which actions and workflows can run across your enterprise, organization, or repository, reducing supply-chain risk. ([GitHub Changelog](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available))
- **Ubuntu 26 runner image is now generally available** — The Ubuntu 26.04 runner for GitHub Actions has moved out of preview for production workflows on both x64 and arm64, with a migration path from older images. ([GitHub Changelog](https://github.blog/changelog/2026-09-17-ubuntu-26-generally-available-and-latest-migration))
- **Copilot impact dashboard shows feature engagement** — Enterprise admins can now see how many active users regularly use specific Copilot features, helping target enablement efforts where adoption lags. ([GitHub Changelog](https://github.blog/changelog/2026-09-17-copilot-impact-dashboard-now-shows-feature-engagement))
- **Code scanning AI Scan no longer requires CodeQL default setup** — AI Scan can now find security vulnerabilities in pull requests even without CodeQL default setup enabled, lowering the bar to try it. ([GitHub Changelog](https://github.blog/changelog/2026-09-16-code-scanning-ai-scan-no-longer-requires-codeql-default-setup))
