## Recent GitHub Blog and Changelog stories

- **Copilot canvases for agentic workflows.** New canvases in the GitHub Copilot app make multi-step agent work visible and steerable, so you can follow and adjust what an agent is doing in real time. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/how-canvases-make-agentic-workflows-visible-steerable-and-cost-efficient/))
- **Copilot CLI for legal workflows.** GitHub's own legal team used Copilot CLI to automate repetitive review tasks, a good example of applying the CLI beyond typical coding work. ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/how-the-github-legal-team-used-copilot-cli-to-streamline-their-workflows/))
- **From coder to orchestrator.** As agents take on more implementation work, developers are shifting toward reviewing, directing, and orchestrating multiple agents rather than writing every line themselves. ([GitHub Blog](https://github.blog/developer-skills/career-growth/from-coder-to-orchestrator-how-agents-shift-the-role-of-a-developer/))
- **Reviewing large AI-generated PRs.** Practical tips for splitting a single giant AI-generated pull request into a stack of smaller, reviewable changes. ([GitHub Blog](https://github.blog/engineering/turn-one-giant-ai-generated-pull-request-to-a-reviewable-stack/))
- **Copilot in VS Code, August 2026 releases.** Latest round of Copilot updates for VS Code users. ([GitHub Changelog](https://github.blog/changelog/2026-08-31-github-copilot-in-vs-code-august-2026-releases))
- **Copilot code review: resolution reasons.** Copilot code review now reports why a comment was resolved and adds more review capabilities. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities))
- **Label archiving is generally available.** You can now archive labels instead of deleting them, keeping historical issue/PR data intact. ([GitHub Changelog](https://github.blog/changelog/2026-08-27-label-archiving-is-generally-available))
- **Global model policy is generally available.** Enterprises can now set org-wide policy controlling which AI models are available to Copilot users. ([GitHub Changelog](https://github.blog/changelog/2026-08-26-global-model-policy-generally-available))
