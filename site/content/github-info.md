## Recent updates worth watching

- **Copilot code review can now approve pull requests.** Copilot's automated review can approve PRs directly, not just leave comments, speeding up low-risk review cycles. *(Source: GitHub Changelog)*
- **Refreshed repository pull requests page (public preview).** A redesigned PR list view makes it faster to scan, filter, and triage open pull requests in a repo. *(Source: GitHub Changelog)*
- **Auto resolution and analysis updates in Copilot code review.** Copilot code review can now auto-resolve certain flagged comments and provides deeper analysis context for reviewers. *(Source: GitHub Changelog)*
- **Block pull requests with exposed secrets from merging.** Repos can now require that PRs with detected secrets be blocked from merging until resolved, tightening secret-scanning enforcement. *(Source: GitHub Changelog)*
- **Configure cost and quality in Copilot auto model selection.** Admins and users get more control over how Copilot balances cost versus quality when auto-selecting a model. *(Source: GitHub Changelog)*
- **GitHub CLI media in issues, pull requests, and comments.** The `gh` CLI can now attach images and other media directly to issues, PRs, and comments. *(Source: GitHub Changelog)*
- **Control GitHub Actions cache access with cache mode.** New cache mode settings give finer-grained control over which workflows can read or write Actions caches. *(Source: GitHub Changelog)*
